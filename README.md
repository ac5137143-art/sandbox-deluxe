# Sandbox Deluxe

Падающая песочница для Android: собственный клеточный автомат с теплопроводностью, фазовыми
переходами, химией и взрывами. 60+ материалов, тепловизор, сцены, сохранения, экспорт скриншотов.

Вдохновлено The Sandbox (smellymoo), но с реальной физикой тепла и химии, а не только с песком.

## Скачать APK

Свежая сборка со стороны GitHub Actions:

```
https://github.com/ac5137143-art/sandbox-deluxe/releases/latest/download/SandboxDeluxe.apk
```

APK подписан автоматическим debug-ключом — для установки нужно разрешить установку
приложений из этого источника. Минимальная версия: Android 8.0 (API 26).

## Что внутри

**Движок (`:core`, чистый Kotlin/JVM, без Android)**

* сетка от ~60k до 220k ячеек, один поток симуляции и один поток UI;
* движение по фазам: сыпучие (угол естественного откоса), жидкости (растекание, вязкость,
  вытеснение по плотности), газы и энергия (подъём, рассеивание);
* температура: явная схема теплопроводности с предрасчитанными парами коэффициентов,
  теплоёмкость, источники тепла, теплообмен с воздухом (условие устойчивости учтено);
* фазовые переходы: плавление, кипение, конденсация, замерзание, горение с остатком топлива,
  распад газов и энергии, детонация;
* химия: вода + лава = пар + обсидиан, кислота растворяет металл с выделением водорода,
  соль превращает воду в солёную, кислород разгоняет горение, хлор уничтожает жизнь;
* жизнь: семена прорастают во влажной почве, растения растут к воде, плесень и вирус размножаются;
* механизмы: клонер, аннигилятор, кран, жерло вулкана, нагреватель, морозильник, батарея с проводом;
* сохранение сцен: RLE + gzip (`Codec`), проверка границ при декодировании.

**Приложение (`:app`, Compose + View)**

* `SandView` — Canvas-рендер кадра из `IntArray` пикселей, кисть/линия/рамка/ластик/пипетка;
* `SandboxEngine` — отдельный поток симуляции, команды через lock-free очередь, кадры стабильно
  раз в 16 мс, динамический пересчёт размера сетки под экран;
* Compose-оболочка: HUD со статистикой, панель материалов с поиском, меню сцен/сохранений/настроек,
  тепловизор, инверсия гравитации, три уровня детализации, экспорт в галерею.

## Сборка

Нужны JDK 17, Gradle 8.13 и Android SDK (platform 35, build-tools 35.0.0):

```bash
gradle :core:test        # 28 тестов движка
gradle :app:assembleDebug
```

На серверах с ограниченным доступом к Maven Central можно указать зеркало:

```bash
gradle -Pmirror=https://repo1.maven.org/maven2 :core:test
```

## Проверка движка без телефона

```bash
gradle :tools:demo -PdemoArgs="--bench --bench-steps 400"   # пропускная способность
scripts/make-demo.sh                                        # PNG-кадры сцен + demo.mp4
```

`scripts/make-demo.sh` рисует все восемь сцен в PNG и склеивает из них MP4 (нужен ffmpeg).

## CI

`.github/workflows/build.yml` на каждый push в `main`:

1. ставит JDK 17 и Android SDK;
2. гоняет `:core:test` (28 поведенческих тестов: сохранение массы, отсутствие висящего песка,
   уровняние жидкостей, стратификация нефти на воде, теплопроводность, кипение/конденсация,
   горение, цепная детонация, кислота + металл, жизнь, механизмы, round-trip сохранений);
3. собирает debug APK и публикует его в релизе `latest`.
